# Contributing

This is a living, opinionated repo, and the best thing you can do to it is make it more honest.

Ways to help:

- Bring a study I missed, especially one that argues against something I've claimed.
- Poke holes in an evidence grade. If I've called something Moderate that's really Emerging, tell me.
- Flag anything that reads as overstated, or any place a finding is described without its counter-evidence.
- Fill an open question in [open-questions.md](open-questions.md), or add a new one I have not thought of.
- Add a risk, a theory, a solution, or a policy option to the growing files, with the same grading discipline.
- Point me at a stable link for any source I've flagged as unlinked, especially the Bumble "AI-assisted" badge.

Open an issue or a pull request. Keep the conventions the rest of the repo uses: cite the claim, grade the evidence, keep the counter-evidence in, and write in plain first person with no em dashes and no semicolons.
